## 📚 Guías de uso

### 👤 Guía rápida para usuarios
1. Completá tus tareas pendientes (Checklist).
2. Al terminar, realizá el test.
3. Al aprobar el test, obtendrás nuevos logros.

**Accesos clave**
- ✅ Checklist: /usuario/todo
- 📝 Tests: /usuario/test
- 🏆 Logros: /usuario/logro
- 🎥 Video y artículos: accesibles desde el dashboard y menús

**Cómo leer las tarjetas**
- Icono + título en color
- Título principal en negro y subtítulo en gris
- Cada card es clickeable (stretched-link) con botón “Ir a …”

**Buenas prácticas**
- Ver/leer el contenido antes del test
- Completar todas las tareas del checklist asignadas a tu empresa
- Revisar “Tests pendientes” y “Tests realizados” en la vista de Tests

---

### 🖋 Guía para editores
El panel del editor permite crear y gestionar usuarios, categorías y empresas de manera sencilla, además de herramientas de aprendizaje:

- 🎬 Subir videos que los usuarios deben ver antes de realizar un test
- 📄 Crear artículos como material previo
- 📋 Crear checklists para guiar a usuarios y editores
- 🧪 Diseñar tests para evaluar conocimientos y progreso
- 🏆 Asignar logros automáticamente al aprobar tests

**Navegación y organización**
- Resumen: métricas clave (Empresas, Usuarios, Editores)
- Crear: Artículos, Video, Checklist y Tests (cards grandes, 2 por fila)
- Gestionar: Categorías, Logros y Tareas
- Cards totalmente clickeables con “Ir a …”

**Estándares visuales**
- Color base: #03528A (botones “Crear …”, títulos en color)
- Sidebar activo: #0753f5 (texto/ícono blanco)
- Hover suave en cards de Resumen/Gestionar y borde realzado en “Crear”
- Iconografía e imágenes consistentes (ej. icon-24, img-thumb-40)

**Buenas prácticas**
- Crear primero Empresas y Categorías, luego el contenido (Videos/Artículos)
- Definir Checklists por categoría/empresa para guiar a los usuarios
- Diseñar Tests alineados al contenido y asignar Logros vinculados
- Usar el dashboard para ver totales y desglose por empresa (cuando aplique)
