Guía del editor
Cómo usar el panel del editor
Aqui podras crear y gestionar usuarios, categorías y empresas de manera sencilla. Además, incluye herramientas diseñadas para mejorar la experiencia de aprendizaje:
Cargar videos que los usuarios deben ver antes de realizar un test.
Crear artículos que los usuarios podrán leer como material previo.
Crear checklist para que tanto usuarios como editores puedan seguir el avance de las tareas realizadas.
Diseñar tests para evaluar conocimientos y progreso.
Asignar logros que se otorgarán automáticamente al aprobar cada test.
Para una navegación más ágil, utiliza las tarjetas de Resumen, que ofrecen acceso rápido a cada sección del panel.
